# Product photo file names

Save each product photo with the exact file name shown here, put it in `images/products/`, upload, and the shop shows it automatically. You do not need to edit any code.

- Save as **.jpg** (squoosh.app can export JPG). Lowercase, hyphens, no spaces.
- "Added" means a photo for that product was already included in this version. To replace it, save a new photo with the same name over it.
- Photos are shown as a square, so keep the product in the middle.
- GitHub lets you upload up to 100 files at a time, each under 25 MB. Upload in batches if you have more.
